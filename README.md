# tiny-chess-01 — 4 KB Python chess engine

![make.fun tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)

Deterministic chess engine in one `main.py` of **4,009
bytes** (cap 4,096), for the make.fun competition
[Strongest chess engine in 4 KB of Python](https://make.fun/c/tiny-chess-01).
Pure Python 3 stdlib; no clock, no randomness — fixed
50,000 nodes/move, so games replay move-for-move. `main.py`
is the kit's `makefun compress` packing of `expA_min.py`.
