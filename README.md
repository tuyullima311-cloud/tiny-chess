# tiny-chess-01
![](https://make.fun/badge/tiny-chess-01/tuyullima311-cloud/tiny-chess/rank.svg)
![](https://make.fun/badge/tiny-chess-01/tuyullima311-cloud/tiny-chess/reward.svg)

Deterministic chess engine in one `main.py` (4,009 of 4,096
bytes), for make.fun's Strongest Chess Engine in 4 KB of
Python. Pure Python 3 stdlib, no clock, no randomness: fixed
50,000 nodes/move, games replay move-for-move. `main.py` is
the kit's `makefun compress` packing of `expA_min.py`.
