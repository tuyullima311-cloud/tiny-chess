Deterministic engine in one `main.py` (4,009 bytes),
for [make.fun](https://make.fun/bounty/tiny-chess-01)'s
Strongest Chess Engine in 4 KB of Python. Pure Python 3 stdlib, no clock, no randomness: fixed
50,000 nodes/move. `main.py` is the kit's
`makefun compress` packing of `expA_min.py`.
